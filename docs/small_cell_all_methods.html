Small-cell comparison: all eight methods

16 fixed-cell problems: BCC Cu–Zn and two-sublattice rocksalt (Ti,Zr)(C,N), 8/16/32/48 atoms, targets 0 and −0.1. Each case has one first-shell pair-SRO component. Maximum error, RMS error and MAE are consequently identical. These are not higher-order or cell-shape benchmarks.

The 96 baseline records contain three enumeration variants and Python pair-SRO SA (three seeds). The external/native comparison includes 64 trials: native cuckoo, native SA, ATAT mcsqs and icet, each with seed 42, one worker and five seconds. Cells, compositions and targets match; native initialization differs across engines. The table reports the lowest observed error for each method/case.

The binary pair correlation equals the selected SRO alpha for these equiatomic groups; mappings and best outputs were checked with ATAT corrdump. The added methods use the established ATAT figure score, with the same error ranking for these single-component discrete problems. icet uses a custom matched calculator, not its stock objective. Certified minima are from exhaustive enumeration or a witness attaining a rigorous bound.
